# Architecture

The extension registers QuantitySet in `quantities/` and the optional object field `unit_state`. Activation contributes schema, commands and scoped renderers without migrating items or settings. The directory SDK adapter explicitly provisions missing project schema during creation, after checking peer registrations. Settings are read through the native SDK; `unit.output_budget` is the only package output policy. Other extensions' fields, descriptions, status, claims and relationships are preserved.

The aggregate has version 1, a quantity-set key, immutable observations, immutable derivations and replay receipts. A source reference names native item identity, item hash and field pointer, optionally a citation identity. Native related links connect consuming tasks. Native update comments summarize acquisition or derivation, while structured notes remain data. An observed timestamp is a submitted claim distinct from native history's author/time.

Rationals are signed integer numerator and strictly positive denominator strings, each at most eighty digits. Euclid reduction canonicalizes leading zeros and negative zero. BigInt intermediates contain at most products of bounded operands; reduction and explicit growth checks precede persistence. Dictionary factors are exact: millisecond=1/1000 second, minute=60 seconds, hour=3600 seconds, centimetre=1/100 metre, kilometre=1000 metres, kilogram=1000 grams, kB=1000 bytes, MB=10^6 bytes, GB=10^9 bytes, KiB=1024 bytes, MiB=1048576 bytes, GiB=1073741824 bytes, percent=1/100 ratio. There are no affine, calendar, guessed, financial or executable units. The first slice deliberately refuses compound dimensions rather than erasing their algebra.

Comparison and addition/subtraction require equal dimensions, semantic kinds, subjects, population keys and digests, and time windows. Matching context does not prove a disjoint partition; addition refuses until reviewed declarations provide that witness. Subtraction retains the shared population context and receives a distinct derived semantic kind, so a delta cannot be compared as an observed level. Multiplication/division require matching subject, population and window; dimensionless scales preserve the left dimension, and same-dimension division emits a ratio whose semantic identity uses the complete SHA-256 fingerprint of both operand kinds. The retained expression and operand digests preserve the denominator population even when dimensions cancel. Unknowns remain null with missing operand identities. Interval arithmetic evaluates exact endpoint corners and refuses denominator intervals containing zero; ordering overlapping uncertainty intervals abstains without inferring independence or confidence.

Explanations index the aggregate once, visit each reachable node once, and return all intermediate ASTs, operand digests, declaration pins and limitations as compact `derivation_witnesses`. Dependency quantities are deduplicated separately. Shared subgraphs cannot produce exponential walks or disappear from compressed context.

Expressions are typed binary add/subtract/multiply/divide records referencing existing immutable quantities. Derivations pin both operand digests and the immutable first-release exact-context policy digest, along with limitations. Read-back verifies nested strict schemas, canonical fractions, unique identities, replay result fingerprints, record inventories, source pins, acyclic dependency order and independently reproducible derived values. Out-of-band changes refuse as invalid_record. Future state versions refuse without rewrite. Reviewed compatibility declarations and a bounded general unit AST are later Features; no migration command is shipped because this is the initial schema.

One operation reads one owner and uses native `withExpectedItemRevisions` around its locked `client.update`, including a native comment in that same mutation. Checked IDs must include the owner; unchecked IDs must be empty. No package mutex emulates CAS. Caller revisions never silently rebase a derivation; commutative observation additions may reread and retry at most three times. A same-key same-normalized-request replay returns the original immutable result with the current owner revision separately. A different request with the same key refuses. Creation uses an explicit caller-owned native ID, native create-if-absent and verified duplicate-ID recovery. A lost receipt is reconciled by the same key; an unverified host failure is outcome_unknown, never assumed success. The aggregate is bounded to 128 observations, 128 derivations, 256 replay receipts and 64 KiB; exceeding a limit requires a partition or successor, without deleting receipts.

The host owns authorization and backend selection. The directory host uses public SDK lifecycle methods. Injected hosts must provide independent capability evidence, not merely methods. Upstream pm-cli issues 1399, 1587 and 1588 track native authoritative backend ports and database conformance; arbitrary-provider certification is not claimed. Item-level guarded state does not imply a coherent multi-item snapshot. External source freshness and validity remain unknown; pm-evidence integration is deferred rather than inferred from matching numbers. The generic temporal lifecycle remains core-owned. pm-hypothesis owns competing explanations; pm-http owns HTTP acquisition, and neither package is replaced by this ledger.

JSON and TOON use the same strict versioned envelope and scoped host renderers. The native serialized fitter measures both transports including its own metadata, with default 1600 estimated tokens and a 32 KiB ceiling. The native host currently rejects producer-owned cursors before dispatch; CLI continuation uses the distinct `--cursor` package flag while this SDK release blocker remains open. Packet cursors bind owner revision, query and full-witness projection; omissions and continuations are explicit. Safety identities, numeric values, dependency witnesses, limitations and remedies cannot be truncated. Budget refusal supplies a measured minimum or a null minimum requiring a narrower query. The host SDK only opts read commands into native global output controls. Its later generic shaping can omit a producer refusal, so the final scoped renderer refuses any native string/row/result compaction and enforces the final 32 KiB limit again. The distinct package `--budget` flag preserves measured package refusals without that native post-processing; conflicts with native budget flags refuse. Mutation budgets are reserved before writing and can also be configured through package settings. Native producer continuation and post-processing parity remain tracked SDK release blockers.

Submitted text is shareable data. The SDK secret scanner plus bounded recursive validation refuses credential-shaped content, common email shapes (a heuristic), absolute home paths, control/bidi sequences, malformed Unicode, accessor/prototype/cyclic objects and oversized content before mutation. Instruction text is retained as inert structured data; formulas are never evaluated as code. The runtime reads no source bodies automatically, calls no model/network/shell and enumerates no environment. Native history remains authoritative and can retain prior submissions; redaction and retention must use host history policy. Local author attribution provides no authentication or access control.

Each quantity carries at most sixteen provenance references; derived quantities share that bound after reference union. Larger witness sets refuse rather than truncating source identities. Full expression and reviewed declaration support remains deferred.
