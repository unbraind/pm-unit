# Architecture

Compatibility diagnostics check dimension, meaning and population before window: only an otherwise matching context reports `window_mismatch`. Read-only comparison accepts explicit `across_windows:true` (CLI `--across-windows`), which bypasses only that final mismatch. Omission or `false` keeps strict window equality; malformed boolean inputs refuse. The comparison witness retains both window strings, the opt-in mode and the declared subject, population key/digest, semantic kind and dimension held constant. When those constants differ, `held_constant` is null and comparison still refuses. Equal windows remain valid with either mode. Window strings remain opaque declared scope: equality is exact, and no duration, timezone normalization, chronology or equal exposure is inferred. `ordering` compares the exact values, not their window dates. Population equality denotes the declared cohort/filter definition; it does not establish identical individual membership, measurement methodology, causal validity or source truth across time.

The comparison option does not apply to arithmetic. Cross-window subtraction remains refused with `window_mismatch`; no comparison option is persisted or accepted by the derivation API. Comparison changes no native revision, relationships, replay records or history. Persisted version-1 records remain readable without migration.

The extension registers QuantitySet in `quantities/` and the optional object field `unit_state`. Activation contributes schema, commands and scoped renderers without migrating items or settings. The directory SDK adapter explicitly provisions missing project schema during creation, after checking peer registrations. Settings are read through the native SDK; `unit.output_budget` is the only package output policy. Other extensions' fields, descriptions, status, claims and relationships are preserved.

The aggregate starts at version 1, with a quantity-set key, immutable observations, immutable derivations and replay receipts. Appending its first declaration atomically upgrades that owner to version 2, which requires one to thirty-two declarations. Version-1 state omits that field and keeps its serialization and ordering; existing derivations retain the exact-context-v1 policy digest. Unknown aggregate and declaration versions refuse without rewriting. A source reference names native item identity, item hash and field pointer, optionally a citation identity. Native related links connect consuming tasks. Native update comments summarize acquisition, declaration or derivation, while structured notes remain data. An observed or reviewed timestamp is a submitted claim distinct from native history's author/time.

Rationals are signed integer numerator and strictly positive denominator strings, each at most eighty digits. Euclid reduction canonicalizes leading zeros and negative zero. BigInt intermediates contain at most products of bounded operands; reduction and explicit growth checks precede persistence. Dictionary factors are exact: millisecond=1/1000 second, minute=60 seconds, hour=3600 seconds, centimetre=1/100 metre, kilometre=1000 metres, kilogram=1000 grams, kB=1000 bytes, MB=10^6 bytes, GB=10^9 bytes, KiB=1024 bytes, MiB=1048576 bytes, GiB=1073741824 bytes, percent=1/100 ratio. There are no affine, calendar, guessed, financial or executable units. The first slice deliberately refuses compound dimensions rather than erasing their algebra.

By default, comparison and addition/subtraction require equal dimensions, semantic kinds, subjects, population keys and digests, and time windows. Matching context does not prove a disjoint partition; addition refuses unless its expression explicitly selects a reviewed partition. Subtraction retains the shared population context and receives a distinct derived semantic kind, so a delta cannot be compared as an observed level. Multiplication/division require matching subject, population and window; dimensionless scales preserve the left dimension, and same-dimension division emits a ratio whose semantic identity uses the complete SHA-256 fingerprint of both operand kinds. The retained expression and operand digests preserve the denominator population even when dimensions cancel. Unknowns remain null with missing operand identities. Interval arithmetic evaluates exact endpoint corners and refuses denominator intervals containing zero; ordering overlapping uncertainty intervals abstains without inferring independence or confidence.

`declarePartition` and `unit declare` share the normal mutation path. A declaration has schema version 1, kind `disjoint_partition`, its own immutable namespace, exactly two ordered quantity IDs with canonical digests, a distinct union population key/digest, review attribution/time/rationale and bounded evidence references. Validation checks both pins, different member population keys and digests, equal dimensions/meaning/subject/window, and a union distinct from either member. These are necessary structural checks, not proof of disjointness: source truth and reviewer authority remain host/caller responsibilities. There is no implicit membership lookup or transitive compatibility rule. The declaration cannot override a semantic mismatch, authorize another operator or redirect to corrected observations.

Evaluation and durable read-back use the same declaration resolution and validation functions. The additive result converts the right operand to the left unit, inherits the declared union, retains a distinct derived semantic kind and deduplicates both operand provenance and review evidence. More than sixteen combined references refuses before persistence. Each derivation pins the declaration's full canonical digest; state reads check declaration uniqueness, declaration/replay inventory and result fingerprints, operand pins and independently reproduced results. An explanation collects each reachable declaration once, including those used by intermediate derivations. Legacy explanations omit this optional field. Output fitting measures the entire witness without trimming it.

The public tracker example partitions the eight native items at `0578835e5d5b46aac334bb8368905deb04530b61` into seven Features and one Epic. Acquisition used `git archive` of that public revision and complete SDK reads only in a disposable no-git copy. The fixture retains IDs, native item hashes, types, public commit URL and a content checksum. The acceptance test independently checks disjointness and exhaustive union membership, stores the snapshot as native source evidence, then records and derives 7 + 1 = 8. It does not infer counts from titles or modify a fleet source tracker.

Explanations index the aggregate once, visit each reachable node once, and return all intermediate ASTs, operand digests, declaration pins and limitations as compact `derivation_witnesses`. Dependency quantities are deduplicated separately. Shared subgraphs cannot produce exponential walks or disappear from compressed context.

Expressions are typed binary add/subtract/multiply/divide records referencing existing immutable quantities. Derivations pin both operand digests and either the selected partition declaration or the immutable first-release exact-context policy digest, along with limitations. Read-back verifies nested strict schemas, canonical fractions, unique identities, replay result fingerprints, record inventories, source pins, acyclic dependency order and independently reproducible derived values. Out-of-band changes refuse as invalid_record. Broader compatibility mappings, a bounded general unit AST and weighted ratio aggregation remain explicit follow-up Features. No standalone migration command is required: the native CAS that first records a declaration performs the version transition with its receipt.

One operation reads one owner and uses native `withExpectedItemRevisions` around its locked `client.update`, including a native comment in that same mutation. Checked IDs must include the owner; unchecked IDs must be empty. No package mutex emulates CAS. Caller revisions never silently rebase a derivation; commutative observation additions may reread and retry at most three times. A same-key same-normalized-request replay returns the original immutable result with the current owner revision separately. A different request with the same key refuses. Creation uses an explicit caller-owned native ID, native create-if-absent and verified duplicate-ID recovery. A lost receipt is reconciled by the same key; an unverified host failure is outcome_unknown, never assumed success. The aggregate is bounded to 128 observations, 128 derivations, 32 declarations, 256 replay receipts and 64 KiB; exceeding a limit requires a partition or successor, without deleting receipts.

The host owns authorization and backend selection. The directory host uses public SDK lifecycle methods. Injected hosts must provide independent capability evidence, not merely methods. Upstream pm-cli issues 1399, 1587 and 1588 track native authoritative backend ports and database conformance; arbitrary-provider certification is not claimed. Item-level guarded state does not imply a coherent multi-item snapshot. External source freshness and validity remain unknown; pm-evidence integration is deferred rather than inferred from matching numbers. The generic temporal lifecycle remains core-owned. pm-hypothesis owns competing explanations; pm-http owns HTTP acquisition, and neither package is replaced by this ledger.

JSON and TOON use the same strict versioned envelope and scoped host renderers. The native serialized fitter measures both transports including its own metadata, with default 1600 estimated tokens and a 32 KiB ceiling. The native host currently rejects producer-owned cursors before dispatch; CLI continuation uses the distinct `--cursor` package flag while this SDK release blocker remains open. Packet cursors bind owner revision, query and full-witness projection; omissions and continuations are explicit. Safety identities, numeric values, dependency witnesses, limitations and remedies cannot be truncated. Budget refusal supplies a measured minimum or a null minimum requiring a narrower query. The host SDK only opts read commands into native global output controls. Its later generic shaping can omit a producer refusal, so the final scoped renderer refuses any native string/row/result compaction and enforces the final 32 KiB limit again. The distinct package `--budget` flag preserves measured package refusals without that native post-processing; conflicts with native budget flags refuse. Mutation budgets are reserved before writing and can also be configured through package settings. Native producer continuation and post-processing parity remain tracked SDK release blockers.

Submitted text is shareable data. The SDK secret scanner plus bounded recursive validation refuses credential-shaped content, common email shapes (a heuristic), absolute home paths, control/bidi sequences, malformed Unicode, accessor/prototype/cyclic objects and oversized content before mutation. Instruction text is retained as inert structured data; formulas are never evaluated as code. The runtime reads no source bodies automatically, calls no model/network/shell and enumerates no environment. Native history remains authoritative and can retain prior submissions; redaction and retention must use host history policy. Local author attribution provides no authentication or access control.

Each quantity carries at most sixteen provenance references; derived quantities share that bound after operand and declaration evidence union. Larger witness sets refuse rather than truncating source identities. The owner permits at most 32 declarations within its existing 64 KiB and 256-operation limits. A declaration consumes one replay slot and one native history event. Declarations and derivations never auto-rebase; only observations may retry native CAS. Independent OS-process tests synchronize competing declarations before the native update and require one explicit conflict, then re-review the losing revision. SIGKILL immediately before and after the committed update proves recovery with the original key converges on one declaration and one audit event. These are directory-backend guarantees, not certification of arbitrary injected providers.

## Pagination receipts

Each packet reports the full query total, the rows returned on this page and
the number of rows remaining after this page. Earlier pages do not contribute
to `omitted`. The final page has `omitted: 0` and `continuation: null`.
